## 설계

### 시간 복잡도

배열의 크기를 N이라 하자.

정렬 후 가장 유리한 순으로 선택할 수 있다. 이경우 O(N \* log_2(N))의 시간 복잡도를 사용한다.

위 경우 수학적으로 먼저 선택하는 인원이 항상 이김이 보장된다. 이에 O(1)의 시간 복잡도를 사용한다.

### 공간 복잡도

정렬에 O(N)의 공간 복잡도를 사용한다.
