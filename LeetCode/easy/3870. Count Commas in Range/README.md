# 3870. Count Commas in Range

[링크](https://leetcode.com/problems/count-commas-in-range/description/)

| 난이도 |
| :----: |
|  Easy  |

## 설계

### 시간 복잡도

입력받은 수를 N이라 하자.

직접 1부터 순회하며 판단할 경우 O(N)의 시간 복잡도를 사용한다.

차이값을 사용할 경우 O(1)의 시간 복잡도를 사용한다.

### 공간 복잡도

차이값을 사용할 경우 O(1)의 공간 복잡도를 사용한다.

### 차이

| 내 코드 (ms) | 시간 복잡도 | 공간 복잡도 |
| :----------: | :---------: | :---------: |
|      0       |    O(1)     |    O(1)     |

,(콤마) 가 붙기 시작하는건 1000 이상 부터이다. 이 때 주어진 조건상 콤마가 2자리 이상 붙지 않으므로 1000 이상인 갯수만 센다.

```cpp
int countCommas(int n) { return max(0, n - 1000 + 1); }
```
